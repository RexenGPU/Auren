What is included

A writing surface, not a web page.

AUREN combines a calm editor with genuine page geometry, a private library, and interchange formats that keep your work portable.

01 / EDITOR

Real pages

A4, A3, Letter, Legal and custom sizes. Portrait or landscape, four margins, one to three columns, headers and footers with live page tokens.

02 / FORMATS

Your files, your format

Import and export DOCX, DOC, ODT, RTF, TXT, Markdown, HTML, PDF, and a lossless AUREN format. DOCX uses a custom OOXML importer and exporter.

03 / LIBRARY

A private library

Folders, workspaces, favorites, color labels, previews, autosave, crash-recovery drafts, and a full version history stored on this device.

04 / HISTORY

Versions you can trust

Compare any version with the current document word by word. Automatic snapshots and a “Before restore” copy make every change reversible.

05 / SEARCH

Find the right words

SQLite FTS5 full-text search with accent-insensitive matching and contextual snippets. Search inside your documents, not just their titles.

06 / PRIVACY

No account, no cloud

No telemetry, no analytics, no automatic uploads. Spellcheck dictionaries are bundled. AI is off until you enable it and supply your own key.

Privacy and data

Your documents stay yours.

AUREN is fully usable offline. Your library is a folder of ordinary files on your computer, with an optional SQLite index for fast search.

LOCAL FIRST

No cloud requirement

No sign-in, no sync service, and no AUREN server. Move your library folder anywhere from Settings.

ENCRYPTION

Optional at rest

AES-256-GCM for documents, drafts, versions and templates, with the key protected by Windows DPAPI.

BACKUP

Restore in-app

Create a ZIP backup and restore it from Settings. A safety copy is written first and a failed restore rolls back automatically.

ASSISTANT

AI only when asked

Bring your own OpenAI, Anthropic, Gemini, or OpenAI-compatible key. Document context is sent only after explicit consent.

Questions

Good to know.

Does AUREN need an internet connection?

No. The editor, library, spellcheck dictionaries, and all export pipelines work offline. Internet is only needed if you choose to use the optional AI assistant with your own key.

Where are my documents stored?

By default under %APPDATA%\Auren\library. You can change the location in Settings → Storage; AUREN copies the library and keeps the old copy as a safety backup.

Can Word open what I write?

Yes. DOCX is the primary interchange format with real tables, images, headers, footers, page numbers, columns, and footnotes. Word may reflow pages differently because it uses its own layout engine; use PDF when exact pagination matters.

Is the AI assistant enabled by default?

No. It is disabled until you enable it in Settings, add your own API key, and ask a question. Sharing document text requires a separate consent step.
